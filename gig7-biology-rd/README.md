Project 1: RNA-Seq Thesis Pipeline

You give me the count table. I give you the story, the figures and the chapter.

Methodology (the thinking)
- Check the design: groups, replicates, batch, confounders (age, sex, sequencing run)
- Choose the right model: DESeq2 or edgeR for raw counts, limma-voom for large cohorts
- Set justified cut-offs: low-count filter, FDR < 0.05, |log2FC| > 1
- Check sample quality: PCA, sample correlation, outlier decision
- Use the correct enrichment background (only expressed genes)

2. Technical work (the doing)

- Pull GEO data (GEOparse) and clean the metadata
- Map gene IDs (Ensembl to symbol) and handle duplicates
- Normalize data (size factors, VST/rlog) for plots
- Run DEG analysis with PyDESeq2 or DESeq2
- GO/KEGG enrichment (gseapy / clusterProfiler)
- STRING PPI network and hub genes (degree, betweenness, MCC)
- Reproducible notebook with fixed seeds and saved tables

3. Biology story (the analysis)
- Up and down gene lists, with the top 10 of each explained
- Pathways grouped into 3 to 4 themes
- Hub genes checked against the literature
- One-paragraph storyline linked to your thesis hypothesis
- Limitations and suggested qPCR targets

4. Figures (the polish)
- PCA plot and sample heatmap
- Volcano plot with labelled top genes
- Clustered heatmap with group and batch bars
- GO/KEGG dot plot and bar plot
- PPI network with hub genes highlighted
- Colour-blind-safe palette, 300 DPI PNG and SVG

5. Written text
- Methods section in thesis style
- Results section (4 to 5 paragraphs, following the figures)
- Short discussion points



Project 2: Thesis-to-Manuscript Builder

You give me the thesis. I give you a submission-ready paper, in weeks, not months.

Methodology (the thinking)
- Find the one core story of the thesis
- Choose the target journal first (scope, word limit, reference style)
- Decide what to keep, merge or drop
- Map each thesis chapter to an IMRaD section
- Check reporting guidelines (CONSORT, STROBE, PRISMA, ARRIVE)

2. Technical work (the doing)
- Parse the thesis (Word or PDF) into sections
- Rank key sentences with TF-IDF or embeddings
- Word-budget tool: Intro 500, Methods 800, Results 1,200, Discussion 1,000
- Rebuild figures and tables at journal size (300 to 600 DPI)
- Clean references (DOI lookup, remove duplicates, convert style)
- Readability and similarity checks to avoid self-plagiarism
- Export a formatted .docx file

3. Editing judgment (the analysis)
- Decide which results go in the main text and which go to supplementary files
- Write a tight abstract with exact numbers
- Rewrite the discussion: main findings, limitations, one conclusion
- Fix claims that go beyond the data
- Suggest 3 backup journals

4. Figures and tables (the polish)
- Before/after word-count chart
- Multi-panel figures ()
- Clean three-line tables
- Submission checklist

5. Written text
- Full R and D draft in journal language
- Abstract and keywords
- Cover letter
- Response-to-reviewers template
