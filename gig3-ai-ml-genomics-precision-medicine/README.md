# Gig 3: AI/ML for Genomics and Precision Medicine

Five Google Colab projects on protein structure, multi-omics, genome editing, graph learning and privacy-preserving AI.

| # | Project | Tools |
|---|---|---|
| 1 | [AlphaFold2 + ESM-2 for BRCA1/BRCA2 Variant Effect Prediction](project1-alphafold2-esm2-brca-variant-effect/) | Python, ColabFold / AlphaFold2, ESM-2 (fair-esm), scikit-learn, NGLView, Matplotlib |
| 2 | [Multi-Omics Integration with Transformers for Cancer Subtype Discovery](project2-multiomics-cancer-subtype-discovery/) | Python, Scanpy, AnnData, DNABERT, scGPT, PyTorch |
| 3 | [CRISPR Guide RNA On-Target vs Off-Target Prediction with CNN + LSTM](project3-crispr-grna-cnn-lstm/) | Python, TensorFlow / Keras, Pandas, Matplotlib |
| 4 | [Patient Similarity Network and Survival Prediction with Graph Neural Networks](project4-patient-similarity-gnn-survival/) | Python, PyTorch Geometric, NetworkX, lifelines, scikit-learn |
| 5 | [Federated Learning for Rare Disease Genomics Across 5 Hospitals](project5-federated-learning-rare-disease/) | Python, TensorFlow Federated, TensorFlow, Pandas |

Each folder has a notebook, a README and a requirements file.
