# Gig 2: Genomic RAG and Biomedical NLP

Five Google Colab projects on retrieval-augmented generation (RAG), graph databases, clinical AI, cross-lingual search and molecular dynamics.

| # | Project | Tools |
|---|---|---|
| 1 | [AI-Powered BRCA1 Variant Search Engine Using RAG](project1-brca1-variant-search-rag/) | Python, ChromaDB, Sentence-Transformers, FastAPI, Pandas |
| 2 | [Graph-RAG Pipeline for Gene-Disease Association Discovery](project2-graph-rag-gene-disease/) | Python, Neo4j, ChromaDB, Sentence-Transformers, LLM API |
| 3 | [Clinical Decision Support RAG with PubMedBERT and SNOMED-CT](project3-clinical-decision-support-rag/) | Python, Transformers (PubMedBERT), FastAPI, ChromaDB |
| 4 | [Cross-Lingual Genomic RAG: English to Bengali Search and Translation](project4-cross-lingual-genomic-rag/) | Python, LaBSE (Sentence-Transformers), ChromaDB or FAISS, LLM API |
| 5 | [Molecular Dynamics Simulation for Protein-Ligand Structural Stability](project5-md-simulation-protein-ligand/) | Python, GROMACS, Matplotlib, MDAnalysis |

Each folder has a notebook, a README and a requirements file.
