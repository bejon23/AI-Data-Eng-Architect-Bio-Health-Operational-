# Project 5: Clinical Trial Outcome Prediction

Summarizing 5,000+ trial results to predict future success rates.

## Features
- Clinical trial data collection
- LLM-based trial summarization
- Meta-analysis (pooled effects)
- Survival analysis (Kaplan-Meier)
- Success rate prediction

## Tech Stack
- LLM (GPT-4/LLaMA via LangChain)
- lifelines (survival analysis)
- scikit-learn (ML)
- Plotly (visualizations)

## How to Run
Open `clinical_trial_prediction.py` in Colab.
