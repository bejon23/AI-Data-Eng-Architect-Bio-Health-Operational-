# Project 3: Drug Repurposing Discovery Engine

Mining 1M+ PubMed abstracts for hidden disease-drug associations.

## Features
- PubMed abstract mining (BioPython)
- Sentence-BERT embeddings (BioBERT)
- HDBSCAN clustering
- NetworkX hidden path analysis
- Drug repurposing candidate ranking

## Tech Stack
- BioPython, PubMed API
- Sentence-Transformers (S-PubMedBert)
- HDBSCAN, scikit-learn
- NetworkX

## How to Run
Open `drug_repurposing_engine.py` in Colab.
