# Project 2: Pharmaceutical Competitive Intelligence

Real-time monitoring of 100+ biotech companies from SEC filings & patents.

## Features
- SEC EDGAR API integration
- Google Patents API integration
- Named Entity Recognition (NER)
- AI summarization (GPT-4/LLaMA)
- Real-time alerts (Slack/Email)
- Business insights dashboard

## Tech Stack
- requests, SEC EDGAR API
- spaCy, Transformers (BERT)
- GPT-4 / LLaMA (via LangChain)
- Dash (for dashboard)

## How to Run
Open `pharma_intelligence.py` in Colab.
