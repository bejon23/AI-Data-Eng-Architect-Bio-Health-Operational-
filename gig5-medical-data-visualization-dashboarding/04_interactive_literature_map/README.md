# Project 4: Interactive Literature Map

Network visualization of gene-phenotype relationships from 50,000 publications.

## Features
- Citation network construction
- BERTopic topic modeling
- Interactive network visualization (PyVis/Plotly)
- Gene-phenotype relationship mapping

## Tech Stack
- BERTopic (topic modeling)
- NetworkX, PyVis
- Plotly, D3.js

## How to Run
Open `literature_map.py` in Colab.
