# Gig 1: Computational Drug Discovery and Docking

Five Google Colab projects covering the drug discovery pipeline: screening, stability, resistance, safety and vaccine design.

| # | Project | Tools |
|---|---|---|
| 1 | [Virtual Screening of Natural Products Against Alzheimer's BACE1](project1-bace1-virtual-screening/) | Python, AutoDock Vina, Meeko, Open Babel, Pandas, Matplotlib |
| 2 | [Molecular Dynamics Simulation for Protein-Ligand Stability](project2-md-simulation-gromacs/) | Python, GROMACS, CHARMM-GUI, MDAnalysis, Matplotlib |
| 3 | [Drug-Resistance Mutation Analysis in HIV-1 Protease (Wild vs Mutant)](project3-fep-hiv-protease-resistance/) | Python, GROMACS, AutoDock Vina, Pandas, Matplotlib |
| 4 | [ADMET Prediction Pipeline for FDA-Approved Drugs with DeepChem](project4-admet-deepchem/) | Python, DeepChem, RDKit, Pandas, Seaborn |
| 5 | [Epitope-Based Vaccine Candidate Selection Pipeline](project5-vaccine-epitope-pipeline/) | Python, Biopython, Pandas, ColabFold, Seaborn |

Each folder has a notebook, a README and a requirements file.
